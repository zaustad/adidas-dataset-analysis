Adidas Sales Analysis

Overview

This project analyzes Adidas sales data to identify sales trends, top-performing products, and regional performance.

Dataset

- File: "Adidas_data.xlsx"
- Records: 9,648
- Period: 2020–2021

Tools

- Microsoft Excel
- Data Analysis and Visualization

Key Insights

- Total Sales: 899.9 million
- Units Sold: 2.47 million
- Operating Profit: 332.1 million

Objective

To analyze sales performance and support data-driven business decisions.
